WEEK06 PONG - UNITYPACKAGE KURULUMU

Unity 6000.3.2f1 ve dersin mevcut Week05 URP projesini kullan.
1. Assets > Import Package > Custom Package ile bu paketi import et.
2. Paket, eksik Multiplayer Services ve FishyUnityTransport bağımlılıklarını kurar.
   İnternet ve Git gerekir. Gerekirse Week06 > Install required Relay packages seç.
3. Derleme tamamlanınca Week06 > Prepare and validate project seç.
4. Assets/Scenes/Pong.unity sahnesini aç. Play > Start Host.
5. İkinci instance/build: 127.0.0.1 > Start Client.
6. Kendi kendine maç için Week06 > Build and play automatically (two players).
   Bu menü Windows Development build alır ve iki botu gerçek ağ bağlantısıyla oynatır.

Açıklamalar: Assets/Week06/README.md
Test sonuçları: Assets/Week06/TEST_SONUCLARI.md
Otomatik maçlar: Assets/Week06/AutoMatches/

Unitypackage UPM paketlerini ve kullanıcı hesabını içinde saklamaz.
Unity Cloud projesi pong bağlandı ve Relay etkinleştirildi. Paket, Cloud bağlantısı boşsa bunu otomatik ayarlar. Farklı projeye bağlıysan Week06 > Link to pong Unity Cloud project seç. Gerçek Relay testi 3-2 tamamlandı, misafir RTT 67 ms.
Yerel bot maçları farklı ağda arkadaşla Relay testi yerine geçmez.
